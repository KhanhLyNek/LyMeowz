# ClientDev — source recovery workbench

This is an **experimental** Java ME client workbench for the existing
`LyMeowz.jar`, not a replacement for the shipped JAR.

## Source layout

- `../ClientSRC/src/` — initial CFR output, retained for forensic comparison
- `src/` — generated by CFR with duplicate-member renaming and experimental
  default-package normalization
- `../ClientSRC/resources/` — extracted JAR resources
- `reports/source-audit.md` — imports, source counts and common warnings
- `reports/protocol-analysis.md` — static I/O and command dispatch candidates
- `reports/compile.md` — summarized javac diagnostics
- `build.sh` — compile/build probe

## Java toolchain

Requires **Java 17+**, Bash, Python 3.8+, curl, and `jar`/`javac`.
The script downloads the **MicroEmulator 2.0.4** CLDC 1.1 and MIDP 2.0
API stub jars from Maven Central. These are compile-time API stubs, **not**
a working emulator or a complete J2ME device SDK.

```bash
bash ClientDev/build.sh
```

The script exits nonzero while recovered code does not compile. It does **not**
silently fall back to packaging the original `LyMeowz.jar`.

For an informative CI probe that retains a report on failure:

```bash
bash ClientDev/build.sh --probe
```

Run `.github/workflows/client-workbench.yml` to regenerate `src/` and
reports in the `client-src/workbench` branch.

## Expected limitations

1. CFR cannot recover original symbols, local variable names or comments.
2. The compiled JAR's default-package classes are referenced by
   `main.GameMidlet`. For easier source compilation we **experimentally**
   move the default-package Java classes into package `main` in `src/`.
   This changes JVM binary names and may break reflection/integration.
3. Javac success (if achieved) does not verify rendering, packet
   compatibility, networking, security or game behavior.
4. The reports deliberately do not publish decoded endpoints, secret
   strings, keys or account data.

Do not merge generated output to `main` without test results and permission
to use/redistribute the binary's underlying game resources.
